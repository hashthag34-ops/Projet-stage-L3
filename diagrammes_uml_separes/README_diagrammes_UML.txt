DIAGRAMMES UML DE CLASSES — PLATEFORME DE FORMATION

Les fichiers .puml sont des diagrammes PlantUML séparés par module :
1. uml_01_utilisateurs_profils.puml : comptes et profils.
2. uml_02_formations_inscriptions.puml : formations, candidatures, séances, présences et certifications.
3. uml_03_cours_evaluations.puml : supports de cours et évaluations.
4. uml_04_forum_messages.puml : forum et messages.

Utilisation :
- Ouvrir https://www.planttext.com/
- Copier le contenu d'un fichier .puml dans l'éditeur.
- Générer le diagramme, puis exporter en PNG ou SVG.
- Répéter pour chaque module.

Important :
Ces diagrammes sont des diagrammes de classes orientés base de données, reconstruits à partir du schéma SQL fourni.
Ils décrivent les tables et leurs relations, pas à eux seuls tous les cas d'utilisation ou les scénarios d'interaction de l'application.
Les noms des colonnes et types ont été simplifiés visuellement (par exemple varchar et timestamp) pour améliorer la lisibilité.
